# 🚀 Ready2Interview

## 📌 Overview

Ready2Interview is a full-stack web application designed to help students prepare for technical interviews and placement assessments through structured learning modules, programming concepts, and progress-based preparation.

The platform provides an interactive learning environment where users can register, log in, select programming languages, practice questions, track progress, and improve technical interview readiness.

This project was developed to strengthen full-stack development skills while solving a real-world student placement preparation problem.

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/sarathendluri333/Ready2Interview.git
cd Ready2Interview
```

---

### 2. Install Backend Dependencies

```bash
cd backend
npm install
```

---

### 3. Start Backend Server

```bash
node index.js
```

---

### 4. Open Frontend

Open:

```bash
index.html
```

in your browser
